Walkthrough: Unified Phase 2 & Phase 3 Machine Learning System
We have successfully implemented and verified the Unified Phase 2 & Phase 3 Machine Learning System for the Real Estate Voice Agent.

What Was Implemented
1. Database Schema & Migration (
database.py
)
crm_call_transcripts.is_converted: Added column with automatic database migration check.
dialogue_exemplars Table: Stores proven successful dialogue turns with JSON-serialized vector embeddings, categories, conversion weights, and session references.
query_candidate_properties_soft(): Performs soft SQL queries allowing $\pm 20%$ to $25%$ budget tolerance and joins payment_plans (down payment, monthly installments, duration, possession) to feed candidate pools into ML feature scoring.
2. Multi-Tier Vector Service (
embedding_service.py
)
Primary Tier: Google GenAI gemini-embedding-001 (3072 dimensions) with fallback to text-embedding-004.
In-Memory LRU Cache: Sub-millisecond vector retrieval for repeated user utterances.
Local Fallback: Scikit-Learn TF-IDF character n-gram vectorizer for zero-latency offline operation when external networks fluctuate.
Math Utilities: Robust normalized cosine similarity calculations.
3. Phase 2: Dynamic Few-Shot Dialogue Memory (
dialogue_memory.py
)
15 Cold-Start Seed Corpus: Curated Pakistani real estate objection handling scenarios:
Installment negotiation & down payment flexibility
LDA / CDA / SBCA NOC & legal legitimacy verification
Budget stretching via easy installments
Urgent site visit closing
Overseas Pakistani power of attorney & RDA bank accounts
Price objection & market rate defense
Rental yield & commercial ROI
School & hospital proximity
Possession vs construction timeline guarantees
Utility connections (Sui gas, electricity, water)
Resale liquidity and exit strategy
Corner plot / park-facing premium justification
Hidden costs & transfer tax transparency
Weekend family site visit coordination
Commercial shop vs residential house comparison
Sub-millisecond Retrieval: In-memory numpy vector cache with cosine similarity search.
Dynamic Few-Shot Banner: Injects high-converting exemplar guidance into LLM prompt when similarity exceeds threshold.
Closed-Loop Feedback Ingestion: index_converted_session(session_id) automatically extracts winning turns from booked calls and indexes or reinforces exemplars.
4. Phase 3: ML Property Candidate Recommender (
recommendation.py
)
rank_properties_ml():
Gaussian Budget Curve: Computes smooth bell-curve tolerance score, plus an installment flexibility bonus when a property is slightly above budget but provides an easy payment plan.
Semantic Overlap: Cosine similarity between property description/amenities and caller query.
Location Fit: Weighted scoring for exact sector vs city-wide matches.
Composite Score: Weighted sum ($35%$ budget, $35%$ semantic, $20%$ location, $10%$ features) outputting match score percentages and breakdown.
Unified Context Generator: Combines few-shot sales guidance banner, ML-ranked properties with installment terms, assigned Relationship Manager, and RAG legal brochure data.
5. CRM & Appointment Manager Integration (
crm_store.py
, 
appointment_manager.py
, 
app.py
)
Added crm_store.mark_session_converted(session_id).
appointment_manager.book_appointment() now flags is_converted = 1 and triggers dialogue_memory.index_converted_session().
Both /api/v1/chat and /v1/chat/completions provide ML recommendations and few-shot guidance in their responses.
