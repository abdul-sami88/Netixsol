Challenge: Two Sum (Hash Map Optimization)

Implement two_sum(nums, target) in O(N) linear time and space.

def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        comp = target - num
        if comp in seen:
            return [seen[comp], i]
        seen[num] = i
    return []
